# Tài liệu lưu trữ

Các file trong thư mục này được giữ để audit và tra cứu lịch sử, nhưng đã bị thay thế hoặc không còn
là chỉ dẫn implementation hiện hành. Agent không cần đọc chúng trừ khi task yêu cầu đối chiếu lịch sử.

## Nội dung

- `plans/`: các kế hoạch cũ (`PLAN-M0-M5`, `PLAN2`, `PLAN_NL`, kế hoạch thi công Claude).
- `gemini/`: review, handoff và kế hoạch Antigravity/Gemini của các phase trước.

Nguồn sự thật hiện hành là `AGENTS.md`, `PLAN.md`, `docs/brain/`, `docs/architecture.md` và mã nguồn
đang chạy. Handoff của từng task lịch sử nằm trong `docs/handoffs/`.
