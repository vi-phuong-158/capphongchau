# Evidence và checklist

Các file trong thư mục này là snapshot/bằng chứng của từng đợt review hoặc runbook thao tác. Chúng
không thay thế `AGENTS.md`, `PLAN.md` hay `docs/brain/`; khi có khác biệt, ưu tiên nguồn sự thật hiện
hành và mã nguồn.

Đặc biệt, các snapshot Public Intake V2 có thể mô tả trạng thái trước một lần vá. Không dùng chúng để
suy ra trạng thái commit, migration, deploy hoặc feature flag hiện tại nếu không đối chiếu với Git,
`docs/brain/03-decisions.md` và `docs/brain/04-current-tasks.md`.
